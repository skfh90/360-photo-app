# Interior Preview theme, splash, and bottom navigation

Date: 2026-09-10

## Product

The app is **Interior Preview**: capture a room in 360°, browse saved interiors, and preview them.

## Theme

Light gallery: cream `#F6F1E8`, linen cards, walnut type, terracotta/brass accent. Capture viewfinder stays dark; HUD chips stay light-on-dark.

Splash: cream, isometric room drawing, wordmark **Interior Preview** / **See the room**.

## Navigation

After permissions, a bottom bar: **Capture · Rooms · Preview**.

- Capture: existing guided scan (copy talks about rooms).
- Rooms: grid of `files/rooms/` JPEGs. Empty state invites a capture.
- Preview: 360 viewer for the current room, or empty state.

A finished stitch is copied into the rooms library and is not deleted when starting a new capture.
